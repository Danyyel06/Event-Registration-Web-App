What it does

Everything a faculty event
platform needs.

Six core capabilities work together to take your events from a shared spreadsheet to a polished, self-managing system.

📅
Event Management

Create, edit, and delete seminars, workshops, and departmental events from a clean admin panel. Set titles, dates, venues, and maximum capacity in seconds.

✍️
Student Registration

Students register online with their name, matric number, and email. No accounts, no passwords — just a simple form that works on any device.

🔒
Capacity Enforcement

The system automatically counts registrations before each sign-up. Once an event is full, new registrations are blocked and the button is disabled for everyone.

🎟️
Unique Confirmation Codes

Every student receives a cryptographically generated code (e.g. EVT-A3F9B2) the moment they register. They present it at the door for instant verification.

👥
Participant Lists

Admins can pull up a full attendee list for any event — with name, matric number, email, registration code, and timestamp. Print it or save as PDF in one click.

⏱️
Live Countdown Timers

Each event card displays a colour-coded countdown showing exactly how many days remain. Students see urgency at a glance and are more likely to register early.

Who it's for

Built for two kinds of people.

User type 01

Faculty Admin & Staff

Anyone responsible for organising departmental events — from seminar coordinators to department secretaries. You get a dedicated admin panel to run everything.

  • Secure login with session-based authentication
  • Create and manage unlimited events
  • View real-time registration counts per event
  • Export participant lists as printable PDFs
  • Edit or cancel events at any time

User type 02

Students

Any student looking to attend a faculty event. No account creation required — just find the event, fill in your details, and you're registered in under a minute.

  • Browse all upcoming events in one place
  • See real-time availability and countdowns
  • Register with just a name, matric number, and email
  • Instant unique confirmation code on success
  • Duplicate registration prevention per matric number

How it works

From event creation to
door check-in — four steps.

01
Admin creates an event

The admin logs in and creates a new event — title, description, date, venue, and maximum capacity. It goes live immediately on the public listing.

02
Students browse and register

Students visit the events page, see what's upcoming with live countdowns and spot counts, then fill in a short form to secure their place.

03
Code is issued instantly

On successful registration, the student sees a confirmation page with their unique EVT-XXXXXX code. They screenshot it or write it down before attending.

04
Admin verifies at the door

The admin pulls up the participant list for the event, matches codes at the entrance, and has a clean digital attendance record ready to print or file.
